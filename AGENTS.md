# Project: Five Days to the Siren

## Goal
Build a small beginner-friendly 2D browser game for a child based on the story "Пять дней до Сирены".

## Tech
- Vanilla HTML
- Vanilla CSS
- Vanilla JavaScript
- No frameworks
- No bundlers
- No backend

## Rules
- Keep code simple and readable for a beginner.
- Prefer small functions with clear names over complex abstractions.
- Use placeholder shapes and colors instead of external art assets.
- All UI text must be in Russian.
- One task should implement one visible feature.
- Do not overengineer architecture.
- Do not delete working features unless replacing them with a simpler working version.
- Update README when controls or launch steps change.

## MVP
- Start screen
- Player movement
- Small map with bunker, village, forest
- Resource collection
- Day counter
- Siren on day 5
- Zombie spawn after siren
- Bunker safe zone
- Win/lose states
