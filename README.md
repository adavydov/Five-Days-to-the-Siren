# Пять дней до Сирены

Минимальный каркас браузерной 2D-игры на чистом HTML, CSS и JavaScript.

## Что уже есть
- Стартовый экран с кнопкой **«Играть»**
- Игровое поле (canvas)
- Персонаж **Тюня** как простой placeholder-спрайт
- Управление с клавиатуры: **WASD** и **стрелки**
- Игровое время: **1 день = 20 секунд**
- Счётчик дня и секунд до конца текущего дня
- На **5-й день** включается Сирена
- После Сирены карта получает красный тревожный оттенок и сообщение в UI
- После Сирены из леса появляются простые зомби
- Бункер работает как безопасная зона от зомби
- Состояния **победы** (дожить до конца 5-го дня) и **поражения** (пойман зомби вне бункера)

## Как запустить
1. Скачайте или откройте папку проекта.
2. Откройте файл `index.html` в браузере.

Никакие зависимости или установка не нужны.
